# 04 · ฟีเจอร์และเกณฑ์รับงาน

รูปแบบ: **รหัส · ชื่อ** — ความสำคัญ (P0 ต้องมี / P1 ควรมี / P2 ดีถ้ามี / P3 ภายหลัง) · Phase · สถานะใน v1.1.0
เกณฑ์รับงาน (AC) เขียนให้ทดสอบได้ — ข้อที่มี 🧪 ต้องมี test อัตโนมัติ

สถานะ: ✅ มีใน v1.1.0 (ต้องย้ายเข้าโครงใหม่) · 🔶 มีบางส่วน · ⬜ ยังไม่มี

## A. จดด่วนและ Inbox

### F-01 · แถบจดด่วนจากที่ไหนก็ได้ — P0 · Phase 0 · ✅
- AC1 กดคีย์ลัดจากแอปใดก็ได้ → แถบขึ้นบนจอที่เมาส์อยู่ภายใน 100 ms และพร้อมพิมพ์ 🧪
- AC2 Enter → รายการถูกบันทึกลง Inbox และแถบปิด; Esc/คลิกนอกแถบ → ปิดโดยไม่บันทึก 🧪
- AC3 Shift+Enter → บันทึกและแถบยังเปิดพร้อมช่องว่าง
- AC4 Tab วนประเภท งาน/ไอเดีย/โน้ต และตัวอย่างผลเปลี่ยนตาม
- AC5 ใช้ได้แม้ Hub และโน้ตทุกใบปิดอยู่ (แอปอยู่ใน tray)

### F-02 · อ่านวันเวลาภาษาไทย/อังกฤษ + เดาประเภท — P0 · Phase 0 · ✅
- AC1 ผ่านชุดเทสต์ปัจจุบัน 39 ข้อ และทุกข้อที่เพิ่มในอนาคต ในทุก time zone 🧪
- AC2 ประโยคที่ไม่มีวันเวลา (เช่น "ดูพระจันทร์", "ไปห้าง", "บ้านเลขที่ 12/10" เมื่อผู้ใช้ลบเตือน) ไม่ตั้งเตือนหรือคืนข้อความได้ 🧪
- AC3 เพิ่ม: "ทุก 2 วัน", "ทุกวันจันทร์ พุธ ศุกร์", "สิ้นเดือน", "ก่อนเที่ยง" (Phase 2) 🧪

### F-03 · Inbox — P0 · Phase 0 · ✅
- AC1 มี Inbox ได้ใบเดียวต่อบัญชี (`notes.is_inbox = 1`) แม้ซิงก์จากหลายเครื่อง 🧪
- AC2 ลบ Inbox แล้วจดด่วนครั้งถัดไปสร้างใหม่
- AC3 Inbox เปิดอยู่ระหว่างจดด่วน → รายการโผล่ทันทีโดยไม่ทับสิ่งที่กำลังพิมพ์ 🧪

### F-04 · วางรูปในแถบจดด่วน — P1 · Phase 2 · ⬜
- AC1 Ctrl+V รูปในแถบ → thumbnail ในแถบ, Enter → งาน + รูปใน Inbox

### F-05 · แคปจอแล้วจดต่อ — P1 · Phase 2 · 🔶 (มีแคปจอในโน้ต)
- AC1 คีย์ลัด/ปุ่มในแถบ → เลือกพื้นที่ → แถบจดด่วนเปิดพร้อมรูป → พิมพ์งาน → บันทึกเป็นงาน+รูป
- AC2 แคปบนจอที่สองและ scale ต่างกันได้ภาพตรงพื้นที่ที่เลือก

## B. โน้ตและตัวแก้ไข

### F-10 · Block editor — P0 · Phase 1 · ⬜ (แทน contenteditable ทั้งก้อน)
- AC1 ทุกคีย์ในตาราง `03-ux-ui.md §4.3` ทำงานตามสเปก 🧪
- AC2 พิมพ์ไทยต่อเนื่อง 500 ตัวอักษรโดยไม่มีอักขระหาย/สลับ, Enter ระหว่าง composition ไม่แบ่งรายการ 🧪
- AC3 วางข้อความหลายบรรทัดได้รายการตามสเปก §4.6 🧪
- AC4 ไม่มี HTML ดิบจากผู้ใช้ถูกเก็บหรือ render (ข้อความเก็บเป็น markdown-lite) 🧪
- AC5 Undo/redo ระดับรายการ 50 ขั้น

### F-11 · ส่วนเสร็จแล้ว + ยกเลิก — P0 · Phase 1 · ✅ (ย้าย)
- AC1 ติ๊ก → `checked_at` ถูกบันทึก, รายการไปอยู่ส่วนเสร็จแล้ว, toast ยกเลิกได้ 5 วินาที 🧪

### F-12 · Priority, ดาว, เยื้อง — P0 · Phase 1 · ✅ (ย้าย)

### F-13 · ตัวหนา/เอียง/ขีดเส้นใต้/ขีดฆ่า/ลิงก์ — P1 · Phase 1 · 🔶
- AC1 คีย์ลัด + bubble เมื่อเลือกข้อความ; ส่งออก Markdown ได้รูปแบบตรงกัน 🧪

### F-14 · ไฟล์แนบ: รูป วิดีโอ ไฟล์ โฟลเดอร์ ลิงก์ — P1 · Phase 1–2 · 🔶
- AC1 รูปเก็บเป็นไฟล์ใน `attachments/` + thumbnail ≤ 480 px; ไม่มี base64 ใน DB 🧪
- AC2 การ์ดไฟล์แสดงชื่อ ขนาด ชนิด, ปุ่มเปิดและเปิดโฟลเดอร์
- AC3 เปิดไฟล์ได้เฉพาะไฟล์ที่อยู่ใน `attachments/` หรือ path ที่ผู้ใช้เพิ่มเองผ่านการลาก/เลือก (เก็บใน DB) 🧪
- AC4 ลิงก์โฟลเดอร์จากเครื่องอื่น (หลังซิงก์) แสดงเป็น "อยู่บนเครื่อง <ชื่อ>" และกดไม่ได้

### F-15 · หน้าตาหน้าต่าง: สี, ปักบนสุด, ความโปร่งใส — P0/P1 · Phase 1–2 · 🔶
- AC1 สี 6 สีตาม tokens, ตัวหนังสือบนแถบผ่าน 4.5:1 ทุกสี
- AC2 ความโปร่งใส 60–100% ต่อโน้ต, hover = ทึบชั่วคราว (P1)

### F-16 · หลายโน้ต, คืนตำแหน่งหลังรีสตาร์ต, หลายจอ — P0 · Phase 1 · ✅/🔶
- AC1 ปิดแอปแล้วเปิดใหม่ (รวมปิดเครื่อง Windows) → โน้ตที่เปิดอยู่กลับมาที่เดิม 🧪
- AC2 จอที่เคยใช้หายไป → โน้ตย้ายมาจอหลักโดยไม่ทับกัน 🧪

### F-17 · Dock รวม — P0 · Phase 2 · 🔶 (ตอนนี้เป็นหน้าต่างเล็กต่อโน้ต)
- AC1 ย่อโน้ต → renderer ของโน้ตปิด, แถวขึ้นใน dock พร้อมจำนวนงานค้างและเลยกำหนด 🧪
- AC2 คลิกแถว → โน้ตกลับตำแหน่งและขนาดเดิม

### F-18 · ส่งออก/นำเข้า — P1 · Phase 2 · 🔶 (มีส่งออกต่อโน้ต)
- AC1 ส่งออกโน้ตเป็น .md / .txt / .html / .png
- AC2 "ส่งออกทั้งหมด" → โฟลเดอร์ที่มี `wunwun-export.json` + `notes/*.md` + `attachments/` 🧪
- AC3 นำเข้าจากโฟลเดอร์ส่งออกได้ครบ (round-trip เทสต์) 🧪

- AC2 ติ๊กหรือเลื่อนเวลาใน Hub → โน้ตที่เปิดอยู่อัปเดตทันที 🧪

# 02 · Product: วิสัยทัศน์ หลักการ ขอบเขต

## 1. WunWun คืออะไร

**สมุดจดข้างจอสำหรับงานระหว่างวัน** — คิดอะไรได้ กดคีย์เดียวจดไว้ก่อน แล้วแอปเตือนให้เองเมื่อถึงเวลา

- Tagline: **วันวันทำอะไรบ้าง? จดไว้ตรงนี้ ไม่มีลืม**
- Category: *Desktop work scratchpad* — อยู่ระหว่างโน้ตแปะ (เบาแต่จัดการงานได้น้อย) กับแอป to-do (เก่งแต่ต้องเปิดแอปใหญ่)
- จุดยืน: **ฟรี, ใช้ออฟไลน์ได้ครบ, ข้อมูลเป็นของคุณ, คิดมาเพื่อคนพิมพ์ไทย**

## 2. หลักการ 7 ข้อ (ใช้กรองทุกฟีเจอร์)

1. **จดก่อน** — เก็บได้ทันทีโดยไม่ต้องคิดว่าจะจัดหมวดไหน
2. **ขั้นตอนน้อย** — ไม่ต้องเปิดหน้าต่างใหญ่ ไม่ต้องกรอกช่องเยอะ
3. **เป็นส่วนหนึ่งของเดสก์ท็อป** — tray, คีย์ลัด, ลอยบนจอ, ไม่รู้สึกเป็นเว็บ
4. **อยู่ใกล้ตลอด** — always-on-top และ dock คือตัวตนของแอป
5. **บริบทสำคัญกว่าระบบ** — เก็บรูป ลิงก์ ไฟล์ไว้กับงาน ไม่สร้างระบบโปรเจกต์ซับซ้อน
6. **ข้อมูลอยู่ในเครื่องก่อน** — ทุกอย่างใช้ได้ไม่มีเน็ต ซิงก์เป็นของเสริม
7. **ไม่เป็นภาระเพิ่ม** — ถ้าฟีเจอร์ทำให้ต้องจัดระเบียบมากขึ้น ให้คิดใหม่ (ไม่ทำ Pomodoro, Gantt, dashboard)

## 3. ผู้ใช้หลัก

| คน | งาน | สิ่งที่อยากได้จาก WunWun |
| --- | --- | --- |
| **ฟรีแลนซ์/ดีไซเนอร์** (เช่น ทำงานให้หลายลูกค้า) | งานย่อยเยอะ, ลูกค้าส่งงานทางแชท | จดด่วนตอนคุย, แคปจอ+เขียนว่าแก้อะไร, เตือนวันส่ง |
| **เจ้าของร้านออนไลน์** | เช็ก order, โทร supplier, ทำรูปสินค้า | งานซ้ำทุกวัน, เตือนตามเวลา, รายการวันนี้ |
| **นักพัฒนา/พนักงานออฟฟิศ** | ประชุม, follow-up, งานแทรก | คีย์ลัด, โน้ตลอยข้าง IDE, ไม่ต้องสลับแอป |

## 4. ขอบเขต

- จดด่วน + Inbox, โน้ตลอยหลายใบ, checklist ที่ใช้งานจริง
- เตือนตามเวลา + งานซ้ำ + popup เลื่อนเวลาได้
- มุมมองวันนี้, ค้นหา, งานที่เสร็จแล้ว
- แนบรูป/ไฟล์/ลิงก์/โฟลเดอร์, แคปจอ
- tray, คีย์ลัดตั้งได้, เปิดพร้อมเครื่อง, อัปเดตอัตโนมัติ
- บัญชี + ซิงก์หลายเครื่อง (Windows ก่อน), ลบบัญชีได้
- AI แบบมองไม่เห็น: แตกประโยคเป็นงาน, สรุป (เปิด/ปิดได้)

## 5. ตัวชี้วัดความสำเร็จ

ไม่เก็บ telemetry โดยค่าเริ่มต้น จึงวัดจากสิ่งที่ไม่ต้องติดตามผู้ใช้:

| ตัวชี้วัด | วัดจาก | เป้า |
| --- | --- | --- |
| ยอดดาวน์โหลด | GitHub Releases download count | เพิ่มทุกเวอร์ชัน |
| ผู้ใช้ที่อัปเดต | จำนวนดาวน์โหลด `latest.yml` (electron-updater) | ≥ 60% ของผู้ใช้อัปเดตใน 2 สัปดาห์ |
| ผู้ใช้ซิงก์ | จำนวนบัญชีใน Supabase | — |
| คุณภาพ | issue บน GitHub ที่ติดป้าย `data-loss` | 0 |
| ความเร็ว | ตาม perf budget ใน `10-quality.md` | ผ่านทุก release |
| (ถ้าผู้ใช้ยินยอม) | crash report แบบ opt-in | crash-free sessions ≥ 99.5% |

## 6. ราคาและต้นทุน

- **แอปบนเครื่อง: ฟรีตลอด (MIT)**
- **ซิงก์:** เริ่มบน Supabase Free (DB 500 MB, ไฟล์ 1 GB, โปรเจกต์ถูกพักถ้าไม่มีการใช้งาน 1 สัปดาห์) ซึ่ง **ไม่เหมาะกับผู้ใช้จริง** เพราะการพักโปรเจกต์ทำให้ซิงก์ล่ม → ก่อนเปิดซิงก์ให้คนทั่วไป ใช้ Pro ($25+/เดือน) ([Supabase pricing](https://supabase.com/pricing))
- ทางเลือกคุมต้นทุน: ซิงก์ข้อความฟรี, ซิงก์ไฟล์แนบจำกัดขนาด (รูปย่อเหลือด้านยาว ≤ 1600 px เป็น JPEG, ไฟล์ ≤ 25 MB), เปิดรับบริจาค/Pro ภายหลังถ้าจำเป็น — **ตัดสินใจก่อน Phase 3** (ดู `11-roadmap.md`)
